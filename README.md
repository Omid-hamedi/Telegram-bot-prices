# Telegram-bot-prices
# 💹 ربات تلگرامی قیمت لحظه‌ای ارز، طلا، سکه و ارز دیجیتال

یک ربات تلگرامی توسعه‌یافته با زبان **Python** و کتابخانه‌ی **pyTelegramBotAPI** برای دریافت و نمایش قیمت لحظه‌ای ارزهای خارجی، طلا، سکه و ارزهای دیجیتال.

این ربات علاوه بر نمایش قیمت‌ها، قابلیت‌های کاربردی دیگری مانند ماشین‌حساب تبدیل ارزها و امکانات متنوع دیگر را نیز ارائه می‌دهد.

## ✨ قابلیت‌ها

- 💵 نمایش قیمت لحظه‌ای ارزهای خارجی
- 🪙 دریافت قیمت طلا، سکه و انس جهانی طلا
- ₿ نمایش قیمت ارزهای دیجیتال
- 💲 دریافت قیمت تتر (USDT)
- 🧮 ماشین‌حساب تبدیل ارزها و محاسبه مبالغ
- 📊 دسترسی سریع به اطلاعات قیمت از طریق ربات تلگرام
- ⚙️ پشتیبانی از تنظیمات محیطی برای مدیریت توکن، شناسه‌ها و سایر اطلاعات موردنیاز

## 🛠️ تکنولوژی‌ها و منابع داده

### زبان و کتابخانه اصلی

- **Python** — زبان برنامه‌نویسی پروژه
- **pyTelegramBotAPI** — کتابخانه اصلی برای توسعه و مدیریت ربات تلگرام

### منابع دریافت اطلاعات

| دارایی                       | منبع داده                                                 |
| ---------------------------- | --------------------------------------------------------- |
| دلار، یورو، پوند، درهم و لیر | `algotik-tse`                                             |
| طلا، سکه و انس جهانی طلا     | `algotik-tse`                                             |
| ارزهای دیجیتال               | [CoinGecko](https://www.coingecko.com/)                   |
| تتر (USDT)                   | [nerkh.jahankhahan.shop](https://nerkh.jahankhahan.shop/) |

> دقت و به‌روز بودن قیمت‌ها به عملکرد، محدودیت‌ها و زمان به‌روزرسانی منابع داده بستگی دارد.

## 📦 نصب و راه‌اندازی

### ۱. دریافت پروژه

پروژه را دانلود و از حالت فشرده خارج کنید.

### 📦 نصب وابستگی‌ها

ابتدا مطمئن شوید Python روی سیستم شما نصب است. سپس وابستگی‌های اصلی پروژه را با دستور زیر نصب کنید:

```
pip install pyTelegramBotAPI requests
```

### 📚 کتابخانه‌های استفاده‌شده

| کتابخانه           | کاربرد                                  |
| ------------------ | --------------------------------------- |
| `pyTelegramBotAPI` | ساخت و مدیریت ربات تلگرام               |
| `requests`         | ارسال درخواست به APIها و دریافت قیمت‌ها |

**نکته:** ماژول‌های `json`، `os`، `math`، `re`، `sys`، `io`، `threading`، `time` و `datetime` جزو کتابخانه استاندارد پایتون هستند و نیازی به نصب جداگانه ندارند.

### 🚀 اجرای ربات

پس از نصب وابستگی‌ها، ربات را اجرا کنید:

```
python price_bot.py
```

### ۳. تنظیم متغیرهای محیطی

ربات از متغیرهای محیطی زیر پشتیبانی می‌کند. تنظیم همه آن‌ها اختیاری است و در صورت تنظیم نشدن، مقادیر پیش‌فرض تعریف‌شده در کد استفاده می‌شوند.

| متغیر           | کاربرد                   |
| --------------- | ------------------------ |
| `BOT_TOKEN`     | توکن ربات تلگرام         |
| `ADMIN_ID`      | شناسه مدیر ربات          |
| `SUPPORT_ID`    | شناسه پشتیبانی           |
| `TRC20_WALLET`  | آدرس کیف پول شبکه TRC20  |
| `TON_WALLET`    | آدرس کیف پول شبکه TON    |
| `COINGECKO_KEY` | کلید API سرویس CoinGecko |

**نکته امنیتی:** بهتر است توکن ربات، کلیدهای API و اطلاعات خصوصی در متغیرهای محیطی نگهداری شوند و هرگز در مخزن عمومی گیت‌هاب قرار نگیرند.

### ۴. اجرای ربات

فایل اصلی پروژه را اجرا کنید:

```bash
python price_bot.py
```
